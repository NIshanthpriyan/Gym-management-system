03 / 08 Architecture

System Architecture

Clean separation of concerns across well-defined layers

🖥️ Presentation Layer

HTML5, Bootstrap 5, JavaScript (auth.js, Chart.js)

🔐 Security Layer

JwtAuthenticationFilter → SecurityConfig → RBAC

🎮 Controller Layer

REST endpoints, request validation, response mapping

⚙️ Service Layer

Business logic, transactions, DTO transformations

🗄️ Repository Layer

Spring Data JPA, Hibernate ORM → MySQL 8

Authentication Flow

🌐 Browser → POST /api/auth/login
↓
🔐 AuthenticationManager validates credentials
↓
🎫 JwtTokenProvider generates signed JWT
↓
💾 Token stored in localStorage
↓
🚀 Subsequent requests: Authorization: Bearer <token>

05 / 08 Security

Security Architecture

Enterprise-grade security with JWT stateless authentication and role-based access control

🎫

JWT Tokens

Signed tokens with 24h expiry. Validated on every request by JwtAuthenticationFilter.

🔑

BCrypt Passwords

All passwords are hashed with BCrypt (strength=10). Plain text passwords never stored.

👤

Role-Based Access

Three roles: ROLE_ADMIN, ROLE_TRAINER, ROLE_MEMBER. Each with segregated endpoints.

Protected Endpoint Matrix

Endpoint Pattern ADMIN TRAINER MEMBER
/api/auth/** ✅ Public ✅ Public ✅ Public
/api/members/** ✅ ❌ ⚠️ Own only
/api/trainers/** ✅ ⚠️ Own only ❌
/api/reports/** ✅ ❌ ❌
